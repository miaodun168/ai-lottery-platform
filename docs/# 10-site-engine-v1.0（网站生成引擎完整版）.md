# 一、模块目标

Site Engine（网站生成引擎）

负责：

```text
网站生成

页面生成

模块生成

模板应用

数据绑定

SEO生成

发布部署

站点复制

站点升级

站点备份
```

最终目标：

```text
一句话生成网站
```

例如：

```text
生成一个澳门站

科技蓝风格

50个玩法

10个广告
```

系统自动完成：

```text
创建站点
↓
选择模板
↓
生成页面
↓
绑定数据
↓
发布上线
```
