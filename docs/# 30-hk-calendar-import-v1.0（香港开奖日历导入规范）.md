
---

# 一、设计目标

香港采种：

```text
不是每天开奖

必须按照官方开奖日历运行
```

因此系统必须支持：

```text
提前导入全年开奖计划

提前生成全年预测

根据开奖日历自动触发开奖

自动结算

自动统计
```

---

# 二、核心原则

## 原则1

香港全年最多：

```text
366期
```

---

## 原则2

香港实际开奖数量：

```text
以导入日历为准
```

例如：

```text
2026年

实际开奖：

156期
```

则：

```text
2026香港

总期数=156
```

---

## 原则3

预测生成

按导入期数生成

不是按自然日生成

```
正确：
156期开奖
→ 156组预测

错误：
365天
→ 365组预测
```

---

# 三、数据库设计

## hk_calendar

```sql
CREATE TABLE hk_calendar
(
    id BIGSERIAL PRIMARY KEY,

    year INT NOT NULL,

    period_no VARCHAR(20) NOT NULL,

    draw_date DATE NOT NULL,

    draw_time TIMESTAMP NOT NULL,

    status VARCHAR(20) DEFAULT 'pending',

    created_at TIMESTAMP,

    updated_at TIMESTAMP
);
```

---

# 四、字段说明

| 字段        | 说明   |
| --------- | ---- |
| year      | 年份   |
| period_no | 期号   |
| draw_date | 开奖日期 |
| draw_time | 开奖时间 |
| status    | 状态   |

---


## completed

# 七、导入校验规则

## 校验1

期号不能为空

```text
period_no
```

---

## 校验2

期号唯一

```sql
UNIQUE(year,period_no)
```

---

## 校验3

开奖时间不能为空

---

## 校验4

开奖日期必须属于对应年份

例如：

```text
2026001

开奖日期：

2026-01-01
```

合法。



```text

```

---
