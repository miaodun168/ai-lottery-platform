# 07-attribute-engine-v1.0（属性引擎设计）

> 项目：AI自动建站与自动运维系统
> 模块：Attribute Engine（属性引擎）
> 版本：v1.0
> 状态：核心规则冻结版（第一阶段）

---

# 一、模块目标

属性引擎是整个系统的规则核心。

负责：

```text
号码属性计算

生肖属性计算

五行属性计算

波色属性计算

开奖属性快照生成

玩法属性判定

历史属性回溯

年度生肖映射

年度五行映射
```

整个系统流程：

```text
开奖结果
    ↓
属性引擎
    ↓
玩法引擎
    ↓
结算引擎
    ↓
统计引擎
```
