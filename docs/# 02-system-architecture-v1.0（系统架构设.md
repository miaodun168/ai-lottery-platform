# 玩法模板

重点。

因为：

```text
平特一肖样式A

平特一肖样式B

平特一肖样式C
```

实际上：

```text
规则不变

显示不同
```

必须独立。

结构：

```text
玩法
↓
玩法模板
↓
玩法数据
```

---

---

# 标准玩法结构

```json
{
  "name":"平特一肖",
  "type":"zodiac",
  "period":1,
  "rule":"开奖结果7个号码中有一个生肖命中即中奖"
}
```

---

# 多期玩法

例如：

```text
三期三肖
```

配置：

```json
{
  "period_count":3,
  "target_count":3
}
```

判定：

```text
未来连续3期

有一期命中

即中奖
```

---

# 特码玩法

例如：

```text
大小中特

单双中特

阴阳中特

波色中特
```

判定范围：

```text
仅开奖第7个号码
```

即：

```text
平码不参与
```

---

# 平码玩法

例如：

```text
平特一肖
平特尾
平特码
```

判定：

```text
开奖7个号码全部参与
```

# 特码与平码

固定：

```text
前6个号码

= 特码

最后1个号码

= 平码
```

系统字段：

```json
{
  "special_numbers":[...6个],

  "normal_number":49
}
```
